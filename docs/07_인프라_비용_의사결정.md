## 데이터·비용 경계

- 코어 계산·고전 판단은 DB 없이 로컬 재현 가능해야 한다. 계정/보관함/대화/주문 기능에는 Supabase가 필수.
- 개발용 GPT-4o mini의 Data Sharing 일 250만 토큰 혜택은 **계정 확인 전 사용자 제공 가정치**. 내부 목표 200만 토큰/일 등은 환경별 한도로 적용하되 실제 사용 자격/공유 조건 확인 필요. 실제 고객 데이터를 무료 토큰 확보 목적으로 공유하지 않는다.
- R02는 섹션당 스트림 API 호출로 프롬프트 중복 비용이 늘 수 있다. 섹션/토큰 상한·캐시·비식별 비용 로깅. R03은 사용자당 한도·동시 요청 1개·일 예산을 별도 검증.
- Supabase, Vercel 및 PG 공급자의 무료/유료 정책·호스팅 스트리밍 한도는 실제 연결 전 콘솔/공식 문서에서 확인해야 하며 보장하지 않는다.
- 테스트 PG의 시뮬레이션 승인과 정식 실결제는 운영·계약·개인정보·환불 절차가 완전히 다르다. 이번 구현에는 라이브 결제가 없다.

## 보류된 선택

서비스명·상품명·캐릭터명, 정식 가격/유료 질문 정책, PG 운영사/라이브 키, 비회원 저장형 상담, 데이터 법정 보관 기간과 실제 출시 일정은 사용자 승인 전 확정하지 않는다.

## v2.5 — 실제 API 테스트 예산 별도 제한

개발자 실API 호출은 기존 제품 전체 예산과 **별도, 더 낮은 기본 상한**(예: 15회/일, 30,000토큰/일, 최대 동시성 1)을 둔다. 장문 리포트는 **섹션별 API 호출 수**만큼 비용을 소모하므로 실행 전 예상 상한을 보여준다. 서버가 호출 전 예약→완료 후 실제 usage로 정산한다. 외부 Usage/청구 내역과 대조하며 무료 데이터 공유 토큰 혜택은 실제 계정 적용을 검증하기 전까지 미확정이다. `21_실제_OpenAI_API_테스트_설계.md` 참조.
