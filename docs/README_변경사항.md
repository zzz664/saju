# v1.9 — npm 재시작 및 기능 단위 PR 게이트

- 기존 저장소 보관/백업/아카이브 관련 지시 전부 제거. 초기화 대상·범위 확인 및 별도 위험 작업 승인 원칙 유지.
- npm 전용 정책 유지.
- `develop` 기준 기능 브랜치, **기능 1개당 PR 1개**, PR 대상 `develop`.
- 사용자 PR 검토 및 `develop` 머지 확인 **전에는 다음 작업 진행 금지**.
- 머지 확인 후 로컬 기능 브랜치 `git branch -d`로 안전 정리, `develop` 동기화 후 다음 기능 착수.
- GitHub Actions CI 초기 필수 아님. 로컬 테스트와 PR 리뷰는 필수.
- 기존 manseryeok / GPT-4o mini / 인프라 및 핵심 기능 계획 유지.
- 문서 변경만 수행했으며 실제 저장소 초기화·삭제는 수행하지 않음.
