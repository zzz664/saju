> **v2.4가 최신 기준 문서**입니다. v2.3부터 유지한 코어·11개 기능·가상 캐릭터·모바일 퍼스트·Google/Kakao 로그인·Supabase·PG 테스트 연동 설계에 대화형 해석 경험을 추가합니다. 실제 서비스 구현/DB 적용/API 호출은 수행하지 않았습니다.

## v2.4 핵심 변경

1. P06 풀이 결과 화면을 **캐릭터 말풍선이 실제 스트리밍으로 순차 증가하는 메신저형 UI**로 교체. 단순 타이핑 애니메이션이 아닌 Responses API 스트리밍 연동 설계.
2. **전체 풀이 생성, 사후 검증 및 DB 저장 성공 시에만** 후속 질문 UI와 서버 API를 활성화. 미완료/실패 시 차단.
3. 같은 분석의 **고정 명리 판단, 승인된 풀이, 본인 대화 기록**으로만 질문에 답하고 R01 캐릭터 말투 유지.
4. `R02` 풀이 스트리밍, `R03` 풀이 기반 질의응답 모듈을 서술 계층에 추가. 기존 명리 엔진 M01~M09, F01~F11은 그대로 유지.
5. Supabase 앱 테이블 **10개 → 12개**: `reading_conversations`, `reading_messages`. 추가 SQL은 `db/migrations/0002_reading_conversations.sql`.
6. `19_대화형_스트리밍_풀이_및_후속질문_설계.md` 및 `20_스트리밍_서술_및_후속질문_프롬프트.md` 신규 추가.
7. `examples/responsive-wireframes.html`에 **P06 시뮬레이션(말풍선/완료/질문/응답)** 반영. 실제 API 연결 없는 동작 예시.
8. WBS-60~64 신규 추가: DB 상태 → 리포트 스트림 → P06 UI → 후속 질문 → 통합 QA. **1WBS·1기능 브랜치·1PR, 이전 PR develop 머지 확인 후 다음 착수**.
9. npm 유지, 초기 CI 필수 아님, 색상만 참고·일러스트 사용 금지, 서비스명/상품명/캐릭터명 모두 미정.
