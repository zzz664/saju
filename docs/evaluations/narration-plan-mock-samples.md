# 서술 계획 경로 Mock 검토 샘플

근거 검증 통과: 180/180. 거절 사유: 없음. 사람 자연스러움·가독성 평가: **미실시**.

동일한 반복은 한 샘플로 묶고, 서로 다른 반복 출력은 모두 표시한다. 계획의 근거와 한계를 함께 검토한다.

## N01 윤달 직전 정규 월말

상태: partial. 말풍선: chart, observation, limitations. 고전 해석 일치 5건 / 사용 0건.
- 한계: 일부 판단은 아직 후보 단계라 확정 설명에서 제외했다. 보이는 설명이 전부가 아닐 수 있다.
- 한계: 고전 해석 항목 5건이 조건에 맞지만 승인된 한국어 요약이 아직 없어 해석 문단을 생략했다.
