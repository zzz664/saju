## 집계와 관측

| 구분 | 횟수 | 보고된 결과 |
| --- | --- | --- |
| 유효 사례 (시각 있음·시각 미상) | 12 | 엔진 partial, 해석 말풍선에 카탈로그 요약 인용 출현 |
| 유효 사례의 근거 검증 거절 | 0 / 12 | 거절 사유 코드 분포가 비어 있음 |
| 유효 사례의 문체 점수 1.0 | 11 / 12 | 개별 사례·문체·회차 매핑은 미기록 |
| 유효 사례의 문체 점수 0.8 | 1 / 12 | 개별 사례·문체·회차 및 styleIssues 코드는 미기록 |
| 경도 누락 (설계된 음성 사례) | 6 | 엔진 unavailable, 한계 말풍선만 출력, OUTPUT_REJECTED 없음 |

경도 누락 6회는 설계된 엔진 불가 사례이며 근거 검증 실패 6회로 집계하지 않는다.
문체 점수는 soft 평가다. 0.8점 1회를 근거 검증 거절이나 hard 실패로 바꾸지 않는다.

## 결론

**거절 사유 분포가 비어 있어 프롬프트·검증기 조정 없음**.

`src/domain/narration/prompt.ts`와 `render.ts`를 수정하지 않으며 버전·검증 기준도 변경하지 않는다.
WBS-71은 사용자 보고 실측 기준선 기록 완료로 DONE 처리한다. 자동 테스트의 Mock 결과와
사용자가 실행한 Live 측정은 구분한다.

## 한계와 출시 전 재측정

- **출시 전 재측정이 필요하다.** 유효 12회·음성 6회의 제한된 가상 사례 결과이며 새 사례·모델·프롬프트 변경 후 품질을 보장하지 않는다.
- 출력 원문·출생 입력·토큰 수는 기록하지 않았다. 개별 점수/거절 코드/스타일 이슈의 실행 ID 매핑, 실행 시각, 모델·프롬프트 버전도 제공되지 않아 추정하지 않는다. 비용·토큰 효율이나 출력 의미·자연스러움을 이 기록으로 재검증할 수 없다.
- 이번 표는 사용자 보고 집계를 옮긴 것으로 Codex가 원시 실행 로그나 공급자 사용량을 대조한 증빙이 아니다. 검증을 위해 추가 Live를 호출하지 않았다.
- 출시 전에는 같은 측정 행렬에서 개별 비식별 결과와 버전·거절 사유 코드·문체 점수/이슈·사용량을 함께 기록하고, 출력 원문·개인정보는 이 평가 문서에 넣지 않는다.
