# 페이지 목록 · IA · 모바일 와이어프레임 — v2.4

> 범위: 기존 코어/11개 해석 기능(F01~F11)/캐릭터 말투(R01) 위에 **회원·저장·테스트 주문/결제** 흐름을 연결한다. 서비스명·상품명·캐릭터명은 모두 **미정**. 제공 이미지의 **색채만 반영**하고 일러스트/특정 배치/문구는 가져오지 않는다.
> 상태: 구현용 설계안, 코드가 아직 적용되었다는 의미 아님. P01~P18은 화면 식별자이며 WBS/기능 ID와 구별한다.

## 전역 정보 구조

```text
공개 영역                          로그인 이후
P01 시작 화면                      P09 계정
  ├─ P02 기능 목록                   ├─ P10 출생정보 관리
  │   └─ P03 기능 상세                ├─ P11 저장 풀이
  │       ├─ P04 출생정보             ├─ P15 주문 상세
  │       └─ P05 분석 실행            └─ P16 설정
  └─ P07 소셜 로그인 ─ P08 콜백

P05 분석 실행 ──> P06 메신저형 스트리밍 결과
                       └─ 권한 없을 때 → P12 테스트 결제
                                                   ├─ P13 승인·성공 → P06
                                                   └─ P14 실패/취소
```

- **비회원 체험**: 무료 기능의 입력·분석은 선택적으로 임시 세션만 허용. 영구 저장·구매는 로그인 필수. 임시 출생정보를 브라우저 장기 저장소에 남기지 않는다.
- **11개 기능**: `F01`~`F11` 식별자로 UI·API·DB 연결, 아직 **상품명/가격 미확정**. 테스트 체크아웃은 개발용 `offers` 데이터만 참조한다.
- **권한**: 로그인만으로 유료 기능 해금하지 않는다. 테스트 주문은 테스트 권한만 부여, 운영 구매권과 절대 혼합하지 않는다.

## 공통 모바일 UI 규칙

- 320px까지 기능적 훼손 없이 표시되도록 설계·검증하고 360px, 390px, 430px을 주 기준으로 한다. 모바일 1열/좌우 여백 16px, 카드 반경 20~24px, 터치 최소 44px.
- 태블릿 ≥768px: 본문/도움말 2열 가능. 데스크톱 ≥1024px: `max-width:1200px` 중심 정렬, 본문 읽기 폭 680~760px 제한.
- 색상 토큰: `#F8F5FB` 바탕, `#685DE4` 메인 CTA, `#916FEE` 보조 포인트, `#A99EE1` 라벤더, `#F5D5A8`/`#ECA160` 소량 포인트. **장식용 일러스트·인물·여우·이미지 사용하지 않음.**
- 모바일 하단 내비: 시작/기능/보관/내 계정. 체크아웃·인증 콜백·결과 상세에서는 불필요한 내비를 숨길 수 있음.
- 모든 상태: `loading`, `empty`, `error`, `unauthorized`, `partial`(출생시간 미상), `success` 포함. 서버 응답을 낙관적으로 결제 완료로 표시하지 않음.

## 인수 기준

- 320/360/390/430/768/1024/1440px에서 가로 오버플로 0, 본문 자간·줄바꿈 확인.
- 키보드 탭 이동, 포커스 표기, 버튼 터치 영역, 입력 라벨, 에러 안내, 한글 delta의 누적·줄바꿈 및 채팅 스크롤 처리.
- 로그아웃 상태에서 `/account`, `/checkout`, **저장형** `/results/[analysisId]` 직접 접근 차단. 비회원 저장형 채팅 예외는 만들지 않는다.
- 성공 URL 진입만으로 결제가 완료된 것으로 표시하거나 콘텐츠 권한을 부여하지 않는다.
- 화면별 `loading/empty/error/partial` 시안 확인.
