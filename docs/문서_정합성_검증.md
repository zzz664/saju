## WBS-17 현재 코어 점검

현재 모델은 서버 OPENAI_MODEL 공통 설정(기본 gpt-4o-mini)을 사용한다. 자동 QA에는 개인 CLI 입력을 사용하지 않는다. [코어 QA 기록](evaluations/WBS-17-core-qa.md)의 계산/Mock/문서/화면 증빙과 잔여 항목을 기준으로 하며, 문서의 TODO 또는 목표 아키텍처가 실제 구현 완료를 의미하지 않는다. `npm run check:docs`로 로컬 인라인 링크 파일을 재검사할 수 있다.
