# M01 원국 구조 진단 — WBS-27

`diagnoseStructure(facts, ruleSet?)`는 기존 `DerivedNatalFacts`를 의미 검증한 뒤
순수 함수로 별도 `StructureDiagnosis`를 반환한다. 입력을 바꾸거나 SDK·DB·LLM을 호출하지 않는다.
`schemas.ts`는 엔진 없는 구조 계약이며, 외부 JSON에 스키마를 적용하는 것만으로
명리 내용이나 근거의 진위를 검증했다고 간주하지 않는다.

기존 CoreExport/해시/페르소나 입력은 유지한다. 애플리케이션의
`calculateStructureDiagnosis`는 기존 원국 계산을 한 번 수행하고 `{status, core, structure}`로
감싼다. 원국 계산이 불가하면 `structure: null`이고 사유는 `core.calculation.reasons`에 남는다.
일반 사용자 화면·API나 확정 서술에 자동 연결하지 않는다.

## 채택 정책 1.0.0

`ruleSetId: m01.conservative-structure`, `ruleSetVersion: 1.0.0`의 두 운영화 방식을
기본으로 함께 계산한다. `methods`로 하나만 선택할 수도 있다. 임의 ID/버전/중복/추가 필드는
거절한다. 두 방식은 원전에 그대로 있는 고유 학파명이 아니라 검토 가능한 구현 정책이다.

| method                   | 월령 기준                                 | 통근 기준               | 월령 격국·용신 후보           |
| ------------------------ | ----------------------------------------- | ----------------------- | ----------------------------- |
| `four-season-exact-root` | 寅卯辰木 / 巳午未火 / 申酉戌金 / 亥子丑水 | 일간과 같은 장간 글자   | 월지 본기 십성                |
| `month-qi-element-root`  | 기존 월지 본기의 오행                     | 일간과 같은 오행의 장간 | 투출된 월지 장간, 없으면 본기 |

왕상휴수사는 계절 오행과 일간 오행의 생극 관계로 분류한다. 특히 辰未戌丑에서 두 방식이
다를 수 있다. 사계 묶음은 비교용 단순화이며 원전의 土旺 예외나 절입 후 일수별 사령을
모두 구현했다는 뜻이 아니다. 지장간 본기 우선 순서는 기존 `yuanhai-28-main-first`를
재사용하며 기타 장간 순서를 강도 순위로 해석하지 않는다.

통근은 장간 위치·인덱스·본기 여부를 보존한다. 인성은 통근으로 세지 않는다.
투출은 장간과 연·월·시간의 동일 글자를 연결하며 일간 자체는 제외한다.
시주 등이 없으면 관측된 존재는 보존하되, 미관측을 전체 부재로 바꾸지 않는다.

강약은 월령·해당 통근과 천간/장간의 인비·설극을 함께 본다. 일간 자신을 제외한
비견/겁재/정인/편인은 지원, 식상/재성/관살은 설극 증거로 구분한다. 개수나 점수는 쓰지 않는다.

- 전체 기둥 확정 + 旺/相 + 통근 + 인비 + 설극 미관측: `strong-candidate`.
- 전체 기둥 확정 + 囚/死 + 통근/인비 미관측 + 설극: `weak-candidate`.
- 월령/통근/인비의 지원과 월령/설극의 반대 증거가 공존: `mixed`.
- 그 외 또는 일간/월령 미상: `undetermined`. 시주 미상은 강/약 후보를 확정하지 않는다.

합충·합화, 장간 실효성·강도와 격국 성패는 아직 미평가다. 따라서 강약/격국/용신은
항상 후보이며 최종 신강·신약이나 건록·양인격으로 승격하지 않는다. 원전 원칙을 운영화한
보수적 분기이며 전통 명리 전체를 대체하는 계산식이 아니다.

`patternCandidates`와 `usefulGodCandidates`의 `purpose`(`month-order`/`climate`)를
구분한다. 조후 v1은 확인한 갑·인월의 병/계 후보만 채택한다. 다른 119개 조합은
`CLIMATE_RULE_NOT_ADOPTED`로 명시하고 기본값을 만들지 않는다. 조후는 실제 기온 예측이 아니다.

## 근거·충돌·상태

판정마다 `ruleId`, `ruleVersion`, `methodId`, 우선순위, 출처 ID, 입력 경로/실제 값,
예외와 한계를 반환한다. `catalog.ts`의 출처와 채택 설명을 함께 읽는다.
출처의 원문 대조 범위·검색 색인 한계를 명시하며 전문가 승인으로 표시하지 않는다.
두 방식의 같은 주제 값이나 격국 후보가 다르면 양쪽 judgment ID를 참조하는 미해결
`METHOD_DISAGREEMENT`를 만든다. 우선순위로 한 관법을 보편적 정답으로 선택하지 않는다.

관법 안의 월령 분류/통근·투출 관측은 확정 범위에서 `confirmed`일 수 있지만,
그것이 최종 풀이 확정을 뜻하지 않는다. M01 v1 최상위 `status`는 제한을 보존하여
`partial`, 전 기둥 미상이면 `unavailable`이다. 오류는 원문을 담지 않는 `StructureError`다.

검토·테스트 범위와 원전 링크는 [완료 조건 문서](../../../../docs/evaluations/WBS-27-structure.md)에 있다.
