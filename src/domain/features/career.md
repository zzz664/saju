# F04 직업 적성·업무 성향 — WBS-33

`observeCareer(facts, subject)`는 검증된 원국 facts를 읽는 순수 함수다. F04 실행기는 M03
career의 관측과 기존 후보/보류를 선택한다. M09가 필요한 모듈을 조합하며 간지·십성·강약을 재계산하지 않는다.

## 채택 범위

| 규칙               | 필요한 관측                           | 업무 검토 방향                                                            |
| ------------------ | ------------------------------------- | ------------------------------------------------------------------------- |
| natal-context      | 확정 일간과 월지·본기·본기의 십성     | 업무 성향 검토의 원국 배경만 제시                                         |
| authority-resource | 관살군과 인성군의 서로 다른 실제 증거 | 절차·책임 이해와 자료 학습·업무 적용을 경험/교육/근무 조건에 대조         |
| output-wealth      | 식상군과 재성군의 서로 다른 실제 증거 | 산출물·의사표현과 일정/비용/자원 관리의 연결을 경험/교육/근무 조건에 대조 |

복합 조건과 십성군 분류는 기존 M03 career의 family-pair 규칙을 사용한다. 일간 자체를 비견으로
세거나 장간 순서/출현 개수를 강도·적성 점수로 바꾸지 않는다. 한쪽 단서만 있거나 같은 기호가
여러 번 있어도 새 적성 판단을 만들지 않는다. 미성립은 능력 부족이나 해당 업무 부적합을 뜻하지 않는다.
성별/대운 방향 기준값은 직업·업무 성향 판단에 사용하지 않는다.

facts의 연해자평 십성/장간 분류와 M03의 삼명통회 복합 맥락 출처 ID를 추적한다.
현대 업무 점검 문구는 `policy:f04-work-review-v1`이라는 구현 정책이다. 전문가 승인이나
과학적 직업 적성 검사가 아니며 특정 직업명·추천 목록·채용/승진/연봉/성공·적성 점수를 생성하지 않는다.

## 상태·근거·버전

`f04.observation.*`의 complete/confirmed/accepted는 **기호의 관측 사실**을 뜻한다.
점검 방향은 실제 직업 적합도나 능력의 확정이 아니다. 기존 `m03.career.*`의 후보·보류와
M01 관법 충돌·M02 관계 검토를 보존하고 확정 서술 목록에서는 제외한다.

정상 F04도 M01/M03 해석 한계 때문에 partial이다. 시각 미상은 알려진 기둥만 사용하고
시주에만 있는 단서를 추가하지 않는다. 일간/월주가 미확정이면 관측을 만들지 않으며 코어/필수 모듈
불가는 unavailable로 남긴다. 근거마다 실제 입력 경로/값·출처·정책/규칙 버전·주의·미상 예외를 반환한다.

F04 규칙/실행기 v1.0.0, F04 프로파일/M03 career 투영 v1.1.0을 추적한다.
기존 M03 엔진 v1.0.0·F02/F03 규칙·원국 JSON/해시는 유지한다. F01에서도 같은 코어·M01/M02와
주제별 결과를 재사용하며 다른 하위 기능의 미완료를 숨기지 않는다.

## 검토

`feature-json`에 `{featureId:"F04",birthInput,calculationPolicy}`를 표준입력으로 전달한다.
정상 부분 결과는 stdout JSON/종료 2다. 입력/실행 오류는 기존 고정 stderr 오류 계약에 따른다.
`buildFeatureNarrationInput(result)`는 엔진이 검증한 불변 객체에서 확정 관측만 투영한다.
Mock 소비자에게 후보를 확정으로 전달하지 않으며 외부 JSON 복사본이나 임의 점수 필드로 신뢰 경계를 우회할 수 없다.

이번 범위는 F04 계산·조합·CLI·공통 서술 입력 계약이다. `/dev/api-test`의 core-base/F03 선택지는
유지하며 F04의 R01/Provider·사용자 P06/SSE 연결은 포함하지 않는다. 실제 API 호출은 하지 않았다(LIVE_NOT_RUN).
